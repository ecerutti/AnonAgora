# Diseño específico de la demo

Documentos de diseño específicos de la implementación demo. La demo puede adoptar simplificaciones que no representen el diseño final del sistema.

La estructura interna replica la del sistema general (`design/` raíz): ADRs transversales (`demo/design/adr/`), capa de identidad (`demo/design/capa_de_identidad/`) y aplicaciones destino (`demo/design/aplicaciones/<nombre>/`). Prefijo de ADRs: `DP-XXXX`.

La demo hereda íntegramente las decisiones de diseño del sistema general; aquí solo se registran las simplificaciones, omisiones o sustituciones específicas. Ver `demo/README.md` para la regla de herencia completa.
